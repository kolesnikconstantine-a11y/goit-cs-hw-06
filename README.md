# Веб-додаток із підтримкою сокетів та MongoDB

Це фінальне домашнє завдання курсу комп'ютерних систем, яке демонструє створення веб-додатка на Python без використання сторонніх веб-фреймворків. Додаток містить HTTP-сервер, Socket-сервер для обробки даних форми та інтеграцію з базою даних MongoDB, упаковані в Docker-контейнери.

---

## Функціонал

- **HTTP-сервер:** працює на порту `3000` та забезпечує маршрутизацію для HTML-сторінок і статичних файлів (стилі, зображення).
- **Socket-сервер:** працює на порту `5000` (UDP) і відповідає за прийом даних із веб-форми та їх подальший запис у базу даних MongoDB.
- **Інтеграція з Docker:** проєкт розгортається за допомогою Docker Compose, а база даних зберігає свій стан поза контейнером завдяки механізму Volumes.

---
