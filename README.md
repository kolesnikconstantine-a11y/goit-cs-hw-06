# Веб-приложение с поддержкой сокетов и MongoDB

Это финальное домашнее задание курса компьютерных систем, демонстрирующее создание веб-приложения на Python без использования сторонних веб-фреймворков. Приложение включает в себя HTTP-сервер, Socket-сервер для обработки данных формы и интеграцию с базой данных MongoDB, упакованное в Docker-контейнеры.

## Функционал

- **HTTP-сервер:** работает на порту 3000 и обеспечивает маршрутизацию для HTML-страниц и статических файлов (стили, изображения).
- **Socket-сервер:** работает на порту 5000 (UDP) и отвечает за прием данных из веб-формы и их последующую запись в базу данных MongoDB.
- **Интеграция с Docker:** проект разворачивается с помощью Docker Compose, а база данных сохраняет свое состояние вне контейнера благодаря механизму Volumes.

## Структура проекта

```text
homework 06/
├── main.py                  # Главный файл с логикой HTTP и Socket серверов
├── Dockerfile               # Конфигурация для сборки Docker-образа приложения
├── docker-compose.yaml      # Файл для запуска приложения и MongoDB
├── requirements.txt         # Список зависимостей Python
├── index.html               # Главная страница
├── message.html             # Страница отправки сообщений
├── error.html               # Страница ошибки 404
└── static/                  # Статические файлы
    ├── style.css            # Таблица стилей
    └── logo.png             # Логотип
```

## Инструкция по запуску

Для запуска приложения на твоем компьютере выполни следующие шаги:

1. Убедись, что на твоем компьютере установлены Docker и Docker Compose.
2. Склонируй этот репозиторий и открой его корень в терминале.
3. Запусти сборку и подъем контейнеров с помощью команды:
   ```bash
   docker-compose up --build
   ```
4. После успешного запуска перейди в браузере по адресу `http://localhost:3000`.

## Использование

1. Перейди на вкладку отправки сообщений (страница `/message`).
2. Заполни форму и нажми кнопку отправки.
3. Данные будут обработаны через веб-приложение, отправлены через socket на порт 5000 и сохранены в MongoDB.
4. Ты можешь проверить наличие записей в базе данных с помощью MongoDB Compass, подключившись к `mongodb://localhost:27017` (база данных `message_db`, коллекция `messages`).
